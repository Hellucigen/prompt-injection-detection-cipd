# CIPD-Chat · 中文对话场景下的 Prompt 注入攻击检测

> 自然语言处理课程项目（2026 秋季）· 2-3 人组 · 全程 CPU 可复现

检测发送给 AI 助手的消息中隐藏的**提示注入攻击（Prompt Injection）**——OWASP LLM 应用十大风险之首。攻击者把恶意指令伪装成用户输入或网页内容，诱导大语言模型泄露系统提示词、外传用户隐私或执行违规操作。

**一句话结论**：没有单点银弹。**字符级 n-gram（抗变形 F1≥0.93）与语义向量（未见攻击类别 LOFO 0.95）双通道并联 + 零标注格式异常预警 + LLM 裁判终审**的分层架构，是本数据集实验支撑下的最优部署方案——全部组件 CPU 运行、单条检测 <10ms。

---

## 核心结果

| 实验 | 回答的问题 | 关键数字 |
|---|---|---|
| 主实验（412 条测试集） | RQ1 常规性能 | 规则 P=1.00/R=0.29；字符 n-gram 与语义向量 F1=1.00 |
| LOFO 留一类别外推（六轮） | RQ2 未见攻击泛化 | 词级 TF-IDF 对"数据外渗"新类别仅 **0.15**；语义向量 **0.86**（平均 0.95） |
| 四级对抗变形衰减 | RQ3 对抗鲁棒性 | 规则全盲（≤0.05）；词级装饰崩（0.52）；语义同音崩（0.68）；字符全程 ≥0.93 |

**三个实验的共同故事**：每种文本表示都有各自的盲区，且盲区互不重叠——这正是分层防御架构的数据依据。

## 数据集：CIPD-Chat

首个面向**中文对话场景**的提示注入检测数据集（现有公开集均为英文）：

| 部分 | 设计 | 规模 |
|---|---|---|
| 攻击样本 | 六类别 × ~90 模板（指令覆盖/角色劫持/格式欺骗/间接注入/数据外渗/先天混淆），恶意目标 10 种 × 场景 6 种插槽填充 | train 213 / test 63 |
| 正常对照 | 八类（含**合法角色扮演、严格正常指令、安全话题讨论**三类边界样本） | train 259 / test 99 |
| 对抗变形评测 | L1 emoji 装饰 → L2 同音替换 → L3 拆字 → L4 混合变形 + 未变形对照 | 440 |

**评测协议（关键设计）——双重留出**：测试集的攻击话术模板与恶意目标均为训练时未见（各 30%），衡量"对新花样的泛化"而非"背模板"。初版实验未隔离时学习方法虚高至 F1≈0.99（模板记忆），修正协议后全部重跑——教训写进了报告。

数据为程序合成的模拟对话，不含任何真实用户信息。种子 `20261118` 固定，两步复现。

## 六种检测方法

| 方法 | 原理 | 实验角色 |
|---|---|---|
| M1 规则匹配 | 20 条中文攻击话术正则 | 可解释兜底基线 |
| M2 词级 TF-IDF | 1-2 元词组 + 逻辑回归 | 同分布主力 |
| M2b 朴素贝叶斯 | 词袋计数 + MultinomialNB(α=1) | 课程标准方法对照 |
| M3 字符 n-gram | 字符 1-3 元片段（免分词） | **抗变形主力** |
| M4 语义向量 | bge-small-zh 句向量 + 逻辑回归 | **泛化主力** |
| M5 格式异常 | 六维统计特征 + 95 分位阈值（零标注） | 零日攻击预警 |
| M6 LLM-as-Judge | DeepSeek 结构化判决 | 高可疑流量终审（需 API） |

## 分层检测架构（结论）

```
用户消息
  ↓
第一道闸（毫秒级）：字符 n-gram ∥ 语义向量 双通道并联
    —— 一个抗字形变形，一个抗新话术，互补对方的盲区
  ↓
第二道闸：格式异常评分（零标注，预警训练集中不存在的新型变形）
  ↓
第三道闸：高可疑流量 → LLM 裁判 / 人工复审
```

## 快速复现

```bash
pip install scikit-learn sentence-transformers transformers torch matplotlib
# bge-small-zh 首次运行自动下载；网络受限可设 HF_ENDPOINT=https://hf-mirror.com

python src/build_dataset.py       # ① 生成 CIPD-Chat（种子 20261118）
python src/evaluate.py --fast     # ② 全部实验（CPU <1 分钟）
python src/evaluate.py --judge    # 可选：追加大模型裁判（需 DEEPSEEK_API_KEY）
python src/build_ppt.py           # 可选：重新生成答辩 PPT（数字自动同步）
```

输出：`results/metrics.json`（全部指标）· `results/errors_test.json`（38 条错误案例逐条归因）· `figures/`（四张图）。

## 与课程的联系

方法与评测设计直接对接课程四讲（NLP 概述 / 文本预处理与特征表示 / 机器学习与文本分类 / 分布式语义与词向量）：M2 即课件 TF-IDF 的完整实现；M2b 按课件算例约定（拉普拉斯平滑 α=1）；课件第 3 章"规则方法精确率高、召回率低"的论断被实测复现（P=1.00 / R=0.29）；课件第 2 章警告的数据泄漏（先划分再学词表与 IDF）在本研究初版实验中真实发生并按课件方法修正。

## 局限（诚实声明）

1. 自建语料的分布广度有限——结论定位为方法间相对比较，需接入真实生产流量进一步验证
2. 变形引擎为规则实现，真实攻击者的变形更隐蔽
3. 多模态注入（图片内文字、语音转写通道）未覆盖
4. 检测器自身的"元攻击"（对检测器的注入）未研究
